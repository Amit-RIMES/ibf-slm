How CAP Integration Works

Outbound: Every time a trigger fires, a CAP 1.2 draft alert is auto-generated. Review and edit it here, then click Publish to add it to the public Atom feed at /cap/feed.xml. Register this URL with WMO SWIC or your national CAP aggregator.

Individual XML: Each alert has a direct CAP XML link (click the identifier). The Atom feed links to these so aggregators can ingest the full CAP document.

Inbound: Configure an external Atom feed URL above (e.g. the WMO SWIC feed for your region). When enabled, active alerts appear as an orange layer on the Alert Map, giving duty forecasters regional context from neighbouring countries.

CAP standard: OASIS Common Alerting Protocol v1.2. WMO SWIC: severeweather.wmo.int
